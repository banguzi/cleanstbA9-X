# Lapisan sumber Prayer Times

Salin app/src/main/ ke folder add-on pada checkout upstream commit acuan. Berkas upstream lain (Gradle, font, ikon dan resource) tetap diperlukan. Baca ../../docs/SETUP.md.

Lokasi sengaja disamarkan. Isi config.xml dengan koordinat yang benar, lalu tambahkan dua MP3 sendiri pada res/raw/. Tidak ada APK, audio pengguna, kunci penandatanganan, atau data perangkat di sini.
